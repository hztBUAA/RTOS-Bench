# 实时性能测试 (test-realtime) 使用指南

本文档说明 RTOS-Bench 中的实时性能测试功能 (`test-realtime`)，该功能基于工业操作系统通用基准检测指标体系指导书实现。

## 概述

`test-realtime` 是 RTOS-Bench 的独立子命令，用于测量 RTOS 的基本实时性能指标，包括：

- **上下文切换延迟**: 线程间切换的时间开销
- **信号量操作延迟**: 获取/释放信号量的时间开销
- **互斥锁操作延迟**: 加锁/解锁互斥锁的时间开销
- **内存分配延迟**: malloc/free 的时间开销
- **消息队列延迟**: 发送/接收消息的时间开销（立即执行场景）

## 命令用法

### 基本用法

```bash
# RT-Thread msh 中
msh /> rtbench test-realtime

# Linux 终端中
./rtbench test-realtime
```

### 可选参数

```bash
rtbench test-realtime [OPTIONS]

OPTIONS:
  -m, --multicore    运行多核测试（需要 SMP 支持）
  -q                 安静模式，减少输出
```

### 示例

```bash
# 运行单核测试
msh /> rtbench test-realtime

# 运行单核+多核测试
msh /> rtbench test-realtime --multicore

# 安静模式
msh /> rtbench test-realtime -q
```

## 测试说明

### 单核测试

#### Test 1: 上下文切换延迟

测量两个同优先级线程通过 `yield()` 相互切换的时间开销。

**方法**:
1. 创建两个同优先级线程 A 和 B
2. 线程 A 测量 N 次 `yield()` 的总时间
3. 减去空循环开销
4. 计算单次上下文切换的平均时间

#### Test 4/5: 信号量操作

测量信号量获取 (`sem_take`) 和释放 (`sem_post`) 的延迟。

**测试场景**:
- **Test 4_1 立即执行**: 信号量有资源，无需等待
- **Test 4_2 挂起睡眠**: 信号量无资源，线程挂起等待
- **Test 5_3 低优就绪**: 高优线程释放信号量，唤醒低优先级线程但不切换
- **Test 5_4 高优恢复**: 低优线程释放信号量，唤醒高优先级线程并立即切换

#### Test 6/7: 消息队列操作

测量消息发送 (`mq_send`) 和接收 (`mq_receive`) 的延迟。

**当前实现**:
- **Test 6_1/7_1 立即执行**: 消息队列有空间/消息可用，立即发送/接收

**需要厂商调优的场景**（默认跳过）:
- Test 6_2: 消息发送（挂起睡眠）
- Test 6_3: 消息发送（低优就绪）
- Test 6_4: 消息发送（高优恢复）
- Test 7_2: 消息接收（挂起睡眠）
- Test 7_3: 消息接收（低优就绪）
- Test 7_4: 消息接收（高优恢复）

**注意**: 复杂的消息队列测试场景需要特定的 POSIX mqueue 行为支持，不同平台可能表现不一致。当厂商完成内核调优后，可启用这些测试。

#### Test 8/9: 互斥锁操作

测量互斥锁加锁 (`mutex_lock`) 和解锁 (`mutex_unlock`) 的延迟。

**测试场景**:
- **Test 8_1/9_1 立即执行**: 互斥锁无竞争，立即获取/释放
- **Test 8_2 挂起睡眠**: 互斥锁被占用，线程挂起等待
- **Test 9_3 低优就绪**: 高优线程释放互斥锁，唤醒低优先级线程但不切换
- **Test 9_4 高优恢复**: 低优线程释放互斥锁，唤醒高优先级线程并立即切换

#### Test 10/11: 内存分配

测量动态内存分配 (`malloc`) 和释放 (`free`) 的延迟。

**测试场景**:
- **Test 10_1**: 内存分配 (malloc) 延迟
- **Test 11_1**: 内存释放 (free) 延迟

### 多核测试（待实现）

- **内存带宽**: 不同模式（读/写/拷贝）和并发度下的内存带宽
- **IPC 带宽**: 核间通信带宽
- **任务延迟**: 任务创建/删除延迟

## 技术实现

### 高精度计时

使用架构特定的计时器获取高精度时间戳：

| 架构 | 计时器 | 获取方式 |
|------|--------|----------|
| AArch64 | 系统计数器 | `mrs cntpct_el0` |
| x86_64 | TSC | `rdtsc` |
| RISC-V | time CSR | `rdtime` |
| LoongArch | 稳定计数器 | `rdtime.d` |

### 平台抽象

代码统一使用 POSIX API，支持多个平台：

```c
#include <pthread.h>
#include <semaphore.h>
#include <mqueue.h>

/* 使用 POSIX API */
sem_init(), sem_wait(), sem_post()
pthread_mutex_init(), pthread_mutex_lock(), pthread_mutex_unlock()
mq_open(), mq_send(), mq_receive()
```

### 厂商集成说明

本实现与原始测试程序保持高度一致。以下测试需要厂商完成内核插桩后才能获得与原始程序等价的测试结果：

1. **中断延迟测试 (test2)**: 需要在中断入口/出口添加时间戳记录
2. **系统调用延迟测试 (test3)**: 需要在系统调用入口/出口添加时间戳记录
3. **消息队列复杂场景 (test6_2-6_4, test7_2-7_4)**: 需要确保 POSIX mqueue 的阻塞行为符合预期

当厂商完成上述插桩后，可以通过修改 `test_realtime.c` 中的测试调用逻辑来启用这些测试，实现与原始程序的等价集成。

### 主要差异

1. **跨平台支持**: 原代码仅支持 RT-Thread，本实现通过 POSIX API 支持多平台
2. **命令集成**: 作为 `rtbench` 子命令集成，不作为独立 msh 命令
3. **内核插桩**: 中断延迟和系统调用延迟测试需要内核插桩，暂未实现
4. **多核测试**: 多核测试暂未移植

## 已知限制

1. **中断延迟测试**: 需要修改 RTOS 内核代码添加插桩，暂不支持
2. **系统调用延迟测试**: 需要内核插桩支持，暂不支持
3. **消息队列复杂测试**: 需要厂商调优 POSIX mqueue 实现
4. **多核测试**: 尚未实现
