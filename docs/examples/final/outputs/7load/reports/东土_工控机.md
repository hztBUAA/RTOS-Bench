# 一、测试结果描述（东土-工控机）

本次针对东土-工控机开展的工业实时操作系统基准测试，主要涵盖基础能力、典型负载性能、实时性能和功耗四个方面。

## （1）基础能力测试

基础能力主要考察操作系统的内存访问、文件系统读写、网络通信及POSIX接口兼容性，包括内存带宽、内存延迟、小文件IOPS、大文件IOPS、网络带宽、网络延迟和接口兼容性共7项指标。目前该部分暂无实测数据，评分按占位值60分计。

## （2）典型负载性能测试

典型负载涵盖实时控制、感知计算、通信协同和运维监控四类应用场景，主要通过典型任务的执行时间评价系统对工业应用的支撑能力。在实时控制类负载中PID伺服电机控制任务为 292.043 ms；在感知计算类负载中FAST角点检测任务为 93.197 ms；ICP点云配准任务为 5182.155 ms；在通信协同类负载中Modbus工业协议通信任务为 90029.900 ms；MQTT消息通信任务为 30209.953 ms；在运维监控类负载中EWMA异常检测任务为 1190.518 ms；CUSUM异常检测任务为 703.292 ms。上述指标反映系统在不同工业任务场景下的执行效率，执行时间越短越好。

# 二、测试评分描述（东土-工控机）

基于工业操作系统基准测试评分体系，按照基础能力20%、典型负载性能40%、实时性能30%和功耗10%的权重计算综合得分。

评分公式：总分 = 0.2×F + 0.3×RT + 0.4×T + 0.1×P。

1) 基础能力（权重20%，F）：60.00 分。该分数为占位值，后续需结合内存、文件系统、网络和POSIX接口兼容性测试结果确定。

2) 典型负载性能（权重40%，T = (控制+感知+通信+运维)/4）：实时控制类 98.24 分，感知计算类 97.33 分，通信协同类 79.95 分，运维监控类 94.68 分，四类各占25%，典型负载性能总得分 92.55 分。

3) 实时性能（权重30%，RT = 0.5×基础实时 + 0.5×调度）：基础实时性能 92.23 分，可调度性能 100.00 分，两部分各占50%，实时性能总得分 96.11 分。

4) 功耗（权重10%，P = 四项工况均值）：综合得分 34.57 分。

最终按 0.2×60.00 + 0.3×96.11 + 0.4×92.55 + 0.1×34.57 计算，东土-工控机的综合评分为 81.31 分。

说明：子项得分采用绝对饱和曲线 S = 100×R/(a+R)，a=0.25，基准固定为 SylixOS @ LS2K1000LA；调度得分为 100×(1−平均截止时间错失率)，不参与该曲线。
