# 一、测试结果描述（翼辉-飞腾）

本次针对翼辉-飞腾开展的工业实时操作系统基准测试，主要涵盖基础能力、典型负载性能、实时性能和功耗四个方面。

## （1）基础能力测试

基础能力主要考察操作系统的内存访问、文件系统读写、网络通信及POSIX接口兼容性，包括内存带宽、内存延迟、小文件IOPS、大文件IOPS、网络带宽、网络延迟和接口兼容性共7项指标。目前该部分暂无实测数据，评分按占位值60分计。

## （2）典型负载性能测试

典型负载涵盖实时控制、感知计算、通信协同和运维监控四类应用场景，主要通过典型任务的执行时间评价系统对工业应用的支撑能力。在实时控制类负载中PID伺服电机控制任务为 79.822 ms；在感知计算类负载中FAST角点检测任务为 29.834 ms；ICP点云配准任务为 1635.294 ms；在通信协同类负载中Modbus工业协议通信任务为 9000.985 ms；MQTT消息通信任务为 3002.960 ms；在运维监控类负载中EWMA异常检测任务为 61.974 ms；CUSUM异常检测任务为 51.753 ms。上述指标反映系统在不同工业任务场景下的执行效率，执行时间越短越好。

## （3）实时性能测试

实时性能测试包括基础实时性能和可调度性能。其中：

1) 系统上下文切换延迟为 0.950 μs；

2) 中断响应延迟为 0.336 μs；

3) 任务调度延迟共测试20个场景：信号量获取（立即执行 0.360 μs、挂起睡眠 1.140 μs）；信号量释放（立即执行 0.520 μs、低优先级就绪 0.560 μs、高优先级恢复 1.100 μs）；消息发送（立即执行 1.900 μs、挂起睡眠 2.200 μs、低优先级就绪 2.100 μs、高优先级恢复 2.140 μs）；消息接收（立即执行 1.880 μs、挂起睡眠 4.080 μs、低优先级就绪 2.100 μs、高优先级恢复 4.100 μs）；互斥锁获取（立即执行 0.460 μs、挂起睡眠 1.220 μs）；互斥锁释放（立即执行 0.480 μs、低优先级就绪 0.700 μs、高优先级恢复 1.280 μs）；内存块申请（立即执行 1.220 μs）；内存块释放（立即执行 1.100 μs）；

4) 多核存取性能按1/2/4/8并发度依次为：rd 0.109, 0.218, 0.218, 0.218 GB/s；wr 0.197, 0.287, 0.287, 0.287 GB/s；cp 0.136, 0.228, 0.228, 0.232 GB/s；frd 0.473, 0.95, 0.95, 0.95 GB/s；fwr 0.931, 1.861, 1.861, 1.861 GB/s；fcp 0.856, 1.681, 1.681, 1.681 GB/s；memset 11.411, 12.484, 12.94, 12.971 GB/s；memcpy 1.414, 2.454, 2.452, 2.451 GB/s。

### 可调度性能

可调度性能评价系统在不同处理器利用率下保障周期性任务截止时间的能力。测试采用30%至100%、每10%一个梯度的任务集配置，共8组结果，各梯度错失率依次为：30% 为 0.00%、40% 为 0.00%、50% 为 0.00%、60% 为 0.00%、70% 为 0.00%、80% 为 0.00%、90% 为 0.00%、100% 为 0.00%。所有梯度均未出现截止时间错失。平均截止时间错失率为 0.00%，可调度性能得分为 100.00 分。

## （4）功耗测试

功耗测试覆盖静态空闲、CPU压力、内存压力和文件系统压力四类工况。静态空闲能耗 5521.805 J，CPU压力 1853.149 J，内存压力 2106.812 J，文件系统压力 14102.830 J。

# 二、测试评分描述（翼辉-飞腾）

基于工业操作系统基准测试评分体系，按照基础能力20%、典型负载性能40%、实时性能30%和功耗10%的权重计算综合得分。

评分公式：总分 = 0.2×F + 0.3×RT + 0.4×T + 0.1×P。

1) 基础能力（权重20%，F）：60.00 分。该分数为占位值，后续需结合内存、文件系统、网络和POSIX接口兼容性测试结果确定。

2) 典型负载性能（权重40%，T = (控制+感知+通信+运维)/4）：实时控制类 95.34 分，感知计算类 92.02 分，通信协同类 80.00 分，运维监控类 96.37 分，四类各占25%，典型负载性能总得分 90.93 分。

3) 实时性能（权重30%，RT = 0.5×基础实时 + 0.5×调度）：基础实时性能 86.54 分，可调度性能 100.00 分，两部分各占50%，实时性能总得分 93.27 分。

4) 功耗（权重10%，P = 四项工况均值）：综合得分 69.51 分。

最终按 0.2×60.00 + 0.3×93.27 + 0.4×90.93 + 0.1×69.51 计算，翼辉-飞腾的综合评分为 83.31 分。

说明：子项得分采用绝对饱和曲线 S = 100×R/(a+R)，a=0.25，基准固定为 SylixOS @ LS2K1000LA；调度得分为 100×(1−平均截止时间错失率)，不参与该曲线。
